## 核心理论：$H_{\text{eff}}$ — 基于噪声信道模型的连续推理深度定义（Week 2 主要进展）

### 问题起源

原有逻辑约束熵 $H_G = \sum_{i=1}^{L} \log_2 B_i$ 存在致命盲区：它是一个**一维标量和**，无法区分深窄图和浅宽图。

- **深窄图**：$L=20$，$B_i \equiv 2$，$H_G = 20$ bit → 考验长程一致性与乘性错误坍塌
- **浅宽图**：$L=2$，$B_1=1024$，$H_G \approx 11$ bit → 考验局部高维分类

按旧理论它们"一样难"（甚至可以设计成完全相同 $H_G$），但物理灾难机制完全不同。$H_G$ 把深度和宽度这两个正交维度压扁成了一个数字。

### 理论推导链

#### 第 1 步：推理 = 信号经过串联噪声信道

自回归生成每一步面对 $B_i$ 选 1 的分类问题。正确选项是"信号"，$B_i-1$ 个错误分支是"噪声"。

**核心操作——"抠出 1 比特"**：
- 信号功率统一归一化：$S_i = 1$（任何选择至少需要 1 比特做二元决策）
- 噪声功率：$N_i = \log_2 B_i - 1$（多出来的不确定性才是纯干扰）

这使得信号和噪声在数学上完全正交：
- 当 $B_i = 2$：$N_i = 0$，$\text{snr}_i \to \infty$（理想无噪声信道）
- 当 $B_i$ 很大：$N_i \gg 1$，$\text{snr}_i \to 0$（噪声墙）

#### 第 2 步：全局信噪比

$$\text{SNR}_{\text{global}} = \frac{S_{\text{total}}}{N_{\text{total}}} = \frac{L}{\sum_{i=1}^{L} (\log_2 B_i - 1)}$$

深窄图即使 $L$ 很大，SNR 依然极高；浅宽图即使 $L$ 很小，SNR 骤降。

#### 第 3 步：中断概率分析（深度惩罚的物理来源）

$$P_{\text{success}} = \prod_{i=1}^{L} (1-p_i) \le \exp\left(-\sum_{i=1}^{L} p_i\right)$$

即使每步错误概率 $p_i$ 极小（如 0.01），$L=100$ 时成功率降至 37%。要求准确率 $\ge 1-\epsilon$，必须 $\sum p_i \le \epsilon$。**深度本身就成了风险源。**

#### 第 4 步：有效逻辑熵 $H_{\text{eff}}$

$$H_{\text{eff}} = \sum_{i=1}^{L} \log_2 B_i + \beta L$$

- $\sum \log_2 B_i$：捕获宽度噪声墙效应
- $\beta L$：捕获深度的乘性错误坍塌效应
- $\beta$：深度惩罚系数，由模型架构决定，需实验标定

#### 第 5 步：与随机熵 $H_R$ 的统一

$$H_R = \sum_{i=1}^{L} \log_2 V \quad \text{（纯记忆上限）}$$

$$\Delta \text{NLL}_{\text{eff}} = H_R - H_{\text{eff}} = \sum_{i=1}^{L} (\log_2 V - \log_2 B_i) - \beta L$$

物理含义：模型通过逻辑推理**实际能节省**的信息量。单位统一为 bit，可直接做掺杂实验。

#### 第 6 步：不等错误保护（UEP）加权形式

$$H_{\text{SNR-aware}} = \sum_{i=1}^{L} w_i \log_2 B_i, \quad w_i = e^{\lambda i} \text{ 或 } w_i = 1 + \gamma(i-1)$$

刻画"越往后越脆弱"的物理特性——同样的 $\log_2 B_i$ 出现在第 1 步和第 20 步的破坏力不同。

### 新旧框架对比

| 维度 | 原 $H_G = \sum \log_2 B_i$ | 新 $H_{\text{eff}} = \sum \log_2 B_i + \beta L$ |
|------|---------------------------|------------------------------------------------|
| 参数化维数 | 1 维（标量和） | 2 维（宽度项 + 深度项） |
| 深窄 vs 浅宽 | 不可区分 | 天然解耦 |
| 理论基础 | 纯组合计数 | 有噪信道编码 + 有限长度界 |
| 深度惩罚 | 无 | $\beta L$，有明确物理来源 |
| 可证伪性 | 只能预测"熵越大越难" | 可预测准确率崩塌的二维相变边界 |
| 与 $H_R$ 衔接 | $\Delta \text{NLL} = H_R - H_G$ | $\Delta \text{NLL}_{\text{eff}} = H_R - H_{\text{eff}}$，完全兼容 |

### 理论的已知局限（需诚实对待）

1. **§3.3 信道容量推导是推导链中最弱一环**：$\beta L$ 的最终形式更多来自 §3.2 中断概率直觉 + 物理合理性论证，而非严格的数学推导。不要宣传成"从 Shannon 定理严格导出"。
2. **线性 $\beta L$ 可能是过度简化**：深度惩罚可能超线性（$\beta L^\alpha, \alpha > 1$）甚至指数形式（"lost in the middle"、注意力稀释、位置编码退化）。
3. **假设步间独立**：忽略 Transformer 注意力机制的跨步耦合，只抓一阶主效应。
4. **未区分"记忆衰减"和"错误传播"**：$\beta L$ 把两个不同机制装进了一个参数。

## 已解决的问题

### 1. $H_G$ 盲区 → $H_{\text{eff}}$ 二维解耦 ✅

原 $H_G$ 无法区分深窄图和浅宽图。$H_{\text{eff}} = \sum \log_2 B_i + \beta L$ 将深度和宽度解耦为两个正交维度，一次性解决了这个核心盲区。

### 2. 逻辑熵训练不收敛 ✅

之前尝试用"逻辑熵"作为连续深度度量直接优化，导致 loss 不下降。原因诊断：
- 成功推理的熵不是单调的（低全局均匀性、剧烈信息密度起伏）
- 深度越深，熵可能越发散（IOpenER 现象）
- 熵测量不确定性，不是深度——两者没有单调关系

**解决方式**：放弃直接优化熵，转向 Shannon 信息论框架——用 $H_{\text{eff}}$ 作为分析工具而非优化目标。

### 3. 推理深度连续定义的零突破 ✅

从零开始，基于通信理论构建了 $H_{\text{eff}}$ 定义框架。核心理念：**推理即压缩，深度即噪声**。完成了从问题形式化 → 信道建模 → 中断概率 → $H_{\text{eff}}$ 定义的完整推导链。

### 4. 与记忆线框架的统一对接 ✅

$H_{\text{eff}}$ 与 $H_R$ 单位统一（bit），掺杂实验设计有明确的物理含义（如"30%随机 + 70%逻辑" → $H_{\text{mix}} = 0.3H_R + 0.7H_{\text{eff}}$）。

## 待解决的核心问题

### 🔴 问题 1：$\beta$ 如何测定？

**当前方案**（见 [week2/explanation.md](../week2/explanation.md) 详细推演）：

二维网格实验：扫 $(L, B)$ 网格，找准确率崩塌边界，用崩塌边界上的点做线性回归：

$$L \cdot \log_2 B_{\text{crit}} = C_{\text{phys}} - \beta \cdot L$$

斜率取负即为 $\beta$。

**但这里存在一个严重的 confounding factor（见问题 2）**。

### 🔴 问题 2：模型对推理深度的泛化会不会影响 $\beta$ 的测量？

**这是目前最需要认真对待的核心方法论问题。**

#### 问题描述

The Depth Ceiling 论文揭示了一个关键现象：

> 如果在**低深度**的训练集上训练模型，模型能在 loss 较小的基础上较好地完成 DAG 寻路任务，并且测试发现还有**泛化到更深梯度的能力**。
>
> 然而，如果一上来就给**高深度**的训练集（随机 + 逻辑序列混合），模型**完全不能收敛**，最终学不会探路。

这个现象的含义是：模型的推理能力存在一个"训练深度天花板"——不是模型推理能力的绝对上限，而是训练数据深度超过某个阈值后，学习过程本身就会崩溃。

#### 这对 $\beta$ 测量的影响

在二维网格实验中测 $\beta$ 时，我们实际测量的是：

$$\beta_{\text{measured}} = \beta_{\text{true}} + \beta_{\text{generalization gap}}$$

其中：
- $\beta_{\text{true}}$：模型架构本身的深度惩罚系数（我们想测的物理量）
- $\beta_{\text{generalization gap}}$：模型因训练数据深度分布而产生的泛化偏差

**场景分析**：

| 场景 | 训练深度 | 测试深度 | 测得的 $\beta$ | 问题 |
|------|---------|---------|---------------|------|
| A | 低深度（$L_{\text{train}} \le 5$） | 逐步加深 | $\beta$ 偏小（模型泛化能力强，崩塌边界后移） | 低估了架构本身的深度惩罚 |
| B | 高深度（$L_{\text{train}} \ge 15$） | 逐步加深 | 模型根本不收敛，无法测量 | 实验无法进行 |
| C | 中等深度（$L_{\text{train}} \approx 10$）| 逐步加深 | $\beta$ 接近真实但仍有偏 | 需要校准 |

**核心矛盾**：
- 如果训练深度太低 → 模型泛化到高深度，测得的 $\beta$ 会比真实值**偏小**（因为泛化能力掩盖了部分深度惩罚）
- 如果训练深度太高 → 模型根本不收敛，实验无法进行（天花板效应）
- 我们永远只能在一个"中间地带"测量，而这个测量结果本身是训练深度分布的函数

#### 如何排除泛化效应以测得 $\beta_{\text{true}}$？

**思路 1：控制训练深度分布，做消融实验**

不是在单一训练深度下测 $\beta$，而是在**多个训练深度**下分别测量：

1. 训练 5 个模型，训练数据深度上限分别为 $L_{\text{train}}^{\max} = 3, 5, 8, 12, 16$
2. 对每个模型，在测试时扫 $(L, B)$ 网格测 $\beta_{\text{measured}}(L_{\text{train}}^{\max})$
3. 画 $\beta_{\text{measured}}$ vs $L_{\text{train}}^{\max}$ 曲线
4. 如果曲线趋于平稳（饱和），饱和值接近 $\beta_{\text{true}}$
5. 如果曲线持续下降，说明 $\beta_{\text{measured}}$ 永远包含泛化效应

**关键检验**：如果 $\beta_{\text{measured}}$ 随 $L_{\text{train}}^{\max}$ 增大而增大并收敛到一个上界，那么这个上界就是 $\beta_{\text{true}}$。物理直觉：当训练深度足够大，模型已经没有"多余的泛化余量"可以调用，此时测得的崩塌才是架构本身的限制。

**思路 2：泛化 gap 的显式建模**

将崩塌边界条件扩展为：

$$L_{\text{test}} \cdot \log_2 B + \beta_{\text{true}} \cdot L_{\text{test}} + \gamma \cdot (L_{\text{test}} - L_{\text{train}}^{\max})_+ = C_{\text{phys}}$$

其中 $\gamma$ 是泛化衰减系数，$(x)_+ = \max(0, x)$ 表示只在测试深度超过训练深度时才有额外惩罚。

通过变化 $L_{\text{train}}^{\max}$ 和 $L_{\text{test}}$ 两个维度，可以联合拟合 $\beta_{\text{true}}$ 和 $\gamma$。

**思路 3：训练深度匹配测试深度（消除泛化 gap）**

对每个测试点 $(L, B)$，用**恰好相同深度**的训练数据训练一个模型（或 fine-tune），然后在该点测试。这样 $L_{\text{test}} = L_{\text{train}}^{\max}$，泛化 gap 项 $(L_{\text{test}} - L_{\text{train}}^{\max})_+ = 0$。

但此方案的问题：
- 计算量极大（每个 $(L, B)$ 组合训一个模型）
- 高深度训练可能不收敛，导致该数据点缺失
- 实践中只能做稀疏采样

**思路 4（推荐）：分阶段实验设计**

```
阶段 A：泛化能力标定（先搞清楚泛化本身）
  - 固定一个简单拓扑（如 B=2）
  - 变化 L_train ∈ {2,3,4,5,6,8,10,12}
  - 对每个 L_train，测试模型在 L_test ∈ {L_train, L_train+1, ..., L_train+10} 上的准确率
  - 绘制"泛化衰减曲线"：accuracy vs (L_test - L_train)
  - 目的：量化"模型从训练深度向外泛化时，每多一步损失多少准确率"

阶段 B：β 标定（在控制泛化效应的前提下）
  - 选择 3 个 L_train 水平（低/中/高）
  - 对每个 L_train，只在 L_test ≤ L_train + 合理泛化范围 内扫 (L, B)
  - 对每个 L_test 层，分别回归 β
  - 比较不同 L_train 下的 β 是否一致
  - 如果一致 → β 是稳健物理量，泛化效应已被控制
  - 如果不一致 → β 本身是 L_train 的函数，需要在论文中坦诚并建模

阶段 C：泛化天花板验证
  - 验证 The Depth Ceiling 的发现是否在 $H_{\text{eff}}$ 框架下成立
  - 检验：当 H_eff 超过某临界值时，即使降低训练深度也无法泛化
  - 这直接检验"深度天花板"是否是 H_eff 的函数
```

### 🔴 问题 3：$\beta L$ 的线性假设是否成立？

$H_{\text{eff}} = \sum \log_2 B_i + \beta L$ 中假设深度惩罚是线性的，但实际可能是：

- **超线性** $\beta L^\alpha (\alpha > 1)$：错误滚雪球，越往后越容易错
- **指数** $\beta e^{\lambda L}$：功亏一篑效应，后期脆弱性指数爆炸
- **对数** $\beta \ln L$：注意力机制对长文本的平滑容量，边际递减

**应对策略**（论文叙事三段式）：

1. **阶段一（基准模型）**：提出线性 $H_{\text{eff}}$ 作为一阶近似基准线（Baseline）
2. **阶段二（证伪）**：用实验数据展示反解出的 $\beta$ 不是常数，随 $L$ 退化 → 证明一阶假设不够
3. **阶段三（非线性修正）**：将公式升级为 $H_{\text{eff}} = \sum \log_2 B_i + f(L)$，暴力试错拟合 $f(L)$ 的最优形式。这是论文的真正 Contribution

### 🔴 问题 4：均匀出度实验是否能泛化到非均匀真实拓扑？

**质疑**：现实中图拓扑错综复杂，$B_i$ 忽大忽小，实验中统一出度的理论有什么泛化价值？

**防御策略**：

1. **控制变量法话术**：固定出度 $B_i \equiv B$ 是为了在各向同性（Isotropic）的理想拓扑信道中，实现对深度特征 $f(L)$ 的**纯净测量**。类比物理学中的"无摩擦表面"或"理想气体"——建立普遍定律的必经基准。

2. **几何平均等价映射**：
   $$\sum_{i=1}^{L} \log_2 B_i = L \cdot \log_2 \bar{B}_{\text{geo}}, \quad \bar{B}_{\text{geo}} = (B_1 B_2 \cdots B_L)^{1/L}$$
   任何一个出度不均匀的复杂系统，在信息论尺度上都等价于一个出度恒为 $\bar{B}_{\text{geo}}$ 的均匀系统。

3. **UEP 通用模板**：$H_{\text{eff}} = \sum_{i=1}^{L} w(i, L) \log_2 B_i$，每个 $B_i$ 独立，权重 $w(i, L)$ 从受控实验中拟合得到。

### 阶段 1：泛化能力标定实验

**目的**：在测 $\beta$ 之前，先搞清楚模型对推理深度的泛化规律，为后续 $\beta$ 测量提供校准基线。

#### 实验 1.1：泛化衰减曲线

**逻辑序列构造**：
- 固定 $B = 2$（最简单拓扑，排除宽度干扰，纯粹测量深度效应）
- 训练深度 $L_{\text{train}} \in \{2, 3, 4, 5, 6, 8, 10, 12\}$
- 对每个 $L_{\text{train}}$，生成训练集：每个深度 5000 个不同 DAG（随机种子变化）
- 测试深度 $L_{\text{test}} \in \{L_{\text{train}}, L_{\text{train}}+1, \dots, L_{\text{train}}+10\}$（上限 25）

**关键测量指标**：
- 完全匹配准确率（Exact Match）
- 部分匹配率（前 k 步正确的比例，$k=1,2,\dots,L_{\text{test}}$）
- 首次错误位置分布

**预期产出**：
- 泛化衰减曲线：$\text{accuracy}(L_{\text{test}} | L_{\text{train}})$
- "泛化余量"：模型能比训练深度多走几步？
- 衰减模式：线性衰减？悬崖式崩塌？

**值得探讨的点**：
- 泛化能力是否随 $L_{\text{train}}$ 增加而递减？（训练越深，泛化余量越小？）
- 是否存在一个"临界训练深度"，超过后泛化能力骤降？（与 The Depth Ceiling 呼应）
- 部分匹配率 vs 完全匹配率：模型是在哪一步开始"迷失"的？是逐步退化还是突然崩溃？

#### 实验 1.2：宽度对泛化的调制效应

**逻辑序列构造**：
- 固定 $L_{\text{train}} = 5$
- 变化 $B \in \{2, 4, 8, 16\}$
- 测试时变化 $L_{\text{test}}$ 和 $B_{\text{test}}$（可以 $B_{\text{test}} \neq B_{\text{train}}$）

**目的**：验证"在低宽度下训练的模型，泛化到高宽度时是否更困难？"还是"宽度和深度的泛化是独立的？"

**值得探讨的点**：
- 如果模型在 $B=2$ 训练但在 $B=8$ 测试，深度泛化能力是否衰减？
- 这是否意味着宽度和深度共享同一套"泛化预算"？

### 阶段 2：$\beta$ 测定核心实验

#### 实验 2.1：二维网格崩塌边界扫描（主实验）

**逻辑序列构造**（均匀出度）：

采用**分层 DAG 生成法**（见 [week2/实验设计.md](../week2/实验设计.md)）：
1. 将全图 $V$ 个节点划分到 $L+1$ 个层（Layer $0$ 到 Layer $L$）
2. Layer $0$ 仅包含起点 $s$；Layer $L$ 仅包含终点 $t$
3. 对第 $i$ 层每个节点：随机从第 $i+1$ 层抽取 1 个节点作为正确后继（串联成唯一最短路径），再随机抽取 $B-1$ 个节点作为干扰后继
4. **好处**：生成瞬间即知 $H_G = L \cdot \log_2 B$，无需事后计算

**参数网格**：
- $L$（步数）：$2, 3, 4, 5, 6, 8, 10, 12, 15, 20$
- $B$（每步分支数）：$2, 3, 4, 6, 8, 12, 16, 24, 32, 48, 64, 128, 256, 512, 1024$
- 每个 $(L, B)$ 组合：50 个随机种子 → 共 $10 \times 15 \times 50 = 7500$ 个独立 DAG

**训练策略**（基于阶段 1 的发现调整）：
- 先在多个 $L_{\text{train}}$ 下训练（如 $L_{\text{train}} \in \{3, 5, 8\}$），得到多个模型
- 对每个模型分别测崩塌边界
- 比较不同 $L_{\text{train}}$ 下的 $\beta_{\text{measured}}$

**值得探讨的点**：
- 训练集的深度分布应该如何设计？全部统一深度 vs 混合多种深度？
  - 混合深度可能让模型学到更鲁棒的推理策略，但会引入新的 confounding
  - 建议：先做统一深度（控制变量），再做混合深度（逼近真实场景）
- 训练时 $B$ 应该如何设置？固定 $B$ 还是混合 $B$？
  - 固定 $B$：训练集所有 DAG 出度相同 → 纯净测量
  - 混合 $B$：训练集中包含不同出度的 DAG → 更接近真实分布，但 $\beta$ 的含义变模糊
  - 建议：先在固定 $B$ 下测 $\beta$ 作为"$\beta$ 在特定宽度下的条件值"，再测试 $\beta$ 是否随训练 $B$ 变化

#### 实验 2.2：线性假设检验

**崩塌边界回归**：
- 对崩塌边界上的点，同时拟合三种形式：
  1. $L \cdot \log_2 B = C - \beta L$（线性）
  2. $L \cdot \log_2 B = C - \beta L^\alpha$（幂律）
  3. $L \cdot \log_2 B = C - \beta e^{\lambda L}$（指数）
- 比较 $R^2$、AIC，选最优模型

**$H_{\text{eff}}$ 等高线验证（最关键的证伪检验）**：
- 取崩塌边界上一点 $(L_1, B_1)$，计算 $H_{\text{eff}}^{(1)} = L_1 \log_2 B_1 + \beta L_1$
- 构造 $(L_2, B_2)$ 使 $H_{\text{eff}}^{(2)} = H_{\text{eff}}^{(1)}$（不同 $L$，调整 $B$ 使 $H_{\text{eff}}$ 相等）
- 预测：如果 $H_{\text{eff}}$ = const 是真正的等难度线，两组准确率应该相同
- 如果不同 → $H_{\text{eff}}$ 作为单标量等难度线的假说被推翻，需要更高维描述

**值得探讨的点**：
- 如果线性被拒绝，$f(L)$ 的最优形式是否在不同 $B$ 区间一致？还是说小 $B$ 和大 $B$ 下的深度惩罚机制不同？
- $f(L)$ 是否依赖模型尺寸？对 7B/13B 分别测，预期更大模型 $f(L)$ 增长更慢

#### 实验 2.3：非均匀出度验证（泛化性检验）

**逻辑序列构造**：
- 固定 $L=8$，固定 $\sum \log_2 B_i = 24$（控制总结构熵不变）
- 变化 $B_i$ 分布：
  - 条件 A（深窄）：$B = [2,2,2,2,2,2,2,2]$ → $\sum \log_2 B_i = 8$（总熵不同，需调整）
  - 条件 B（均匀中宽）：$B = [8,8,8,8,8,8,8,8]$ → $\sum \log_2 B_i \approx 24$
  - 条件 C（单步爆炸前端）：$B = [256,2,2,2,2,2,2,2]$ → $\sum \log_2 B_i = 8 + 7 = 15$
  - 条件 D（单步爆炸后端）：$B = [2,2,2,2,2,2,2,256]$
  - 条件 E（递增）：$B = [2,3,4,6,8,12,16,24]$
  - 条件 F（递减）：$B = [24,16,12,8,6,4,3,2]$

**目的**：检验 UEP 加权形式是否必要。如果 $H_{\text{eff}}$（常数 $\beta$）能统一描述所有条件，则加权不必要；如果条件 C 和 D 的崩塌点不同，则 UEP 形式被验证。

**值得探讨的点**：
- "前端爆炸"（第一步噪声极大）vs"后端爆炸"（最后一步噪声极大）：哪个更致命？
  - 前端爆炸 → 模型第一步就可能走错，后续全废
  - 后端爆炸 → 功亏一篑效应，但前期已经建立了正确上下文
  - 如果两者破坏力不同，说明 $w_i$ 不是均匀的——但 $w_i$ 是递增（后端更脆弱）还是递减（前端更致命）？这本身就是一个可发表的新发现

### 阶段 3：掺杂实验（记忆-推理统一框架）

#### 实验 3.1：逻辑-随机连续掺杂

**序列构造方法**：
- **逻辑部分**：按上述分层 DAG 生成，答案序列严格遵循图的最短路径
- **随机部分**：保持前缀（问题描述/图结构）不变，但将答案序列替换为从词典 $V$ 中**无视连通性、纯随机抽样**的 token 串
  - 此处模型面对的是最大随机搜索熵 $H_R = L \cdot \log_2 V$
- **掺杂控制参数** $\gamma \in [0, 1]$：
  - $\gamma = 0$：纯逻辑（$H_{\text{eff}}$）
  - $\gamma = 1$：纯随机（$H_R$）
  - $\gamma = 0.3$：30% 的步使用随机 token，70% 使用逻辑路径

**训练集设计要点**：
- 同一条序列内部掺杂 vs 不同序列之间的掺杂（batch 级掺杂）？
  - **推荐序列间掺杂**：batch 中混合纯逻辑样本和纯随机样本，比例由 $\gamma$ 控制
  - 序列内掺杂（同一序列部分步是逻辑、部分步是随机）会引入诡异的联合分布，模型可能学到奇怪的 shortcut
- 训练时是否告诉模型当前是逻辑还是随机？（类似 task prefix token）
  - 可以尝试两种设置：有 task token（告诉模型这是逻辑任务）vs 无 task token（模型自己判断）
  - 有 task token 能帮助收敛但不够"隐式"

**值得探讨的点**：
- 是否存在一个临界掺杂比例 $\gamma_{\text{crit}}$，超过后模型完全放弃推理转而纯记忆？
- $\gamma_{\text{crit}}$ 是否随 $L$ 变化？深度越大，模型是否越容易"堕落"到记忆策略？
- 不同 $\gamma$ 下，模型的 internal representation 如何变化？（probing 实验）
- 掺杂实验的 loss 曲线是否呈现相变特征？

#### 实验 3.2：$H_{\text{eff}}$–$H_R$ 连续插值验证

**核心预测**：
$$\Delta \text{NLL}_{\text{eff}} = H_R - H_{\text{eff}} = \sum (\log_2 V - \log_2 B_i) - \beta L$$

当 $H_{\text{eff}}$ 接近模型物理压缩上限 $C_{\text{phys}}$ 时，$\Delta \text{NLL}_{\text{eff}} \to 0$，模型退化为记忆/瞎猜。

**实验设计**：
1. 固定 $H_R$（固定 $L$ 和 $V$），逐步降低 $H_{\text{eff}}$（通过降低 $B_i$ 或 $L$）
2. 测量模型实际 NLL 降低量 $\Delta \text{NLL}_{\text{actual}}$
3. 比较 $\Delta \text{NLL}_{\text{actual}}$ 与 $\Delta \text{NLL}_{\text{eff}}$ 的预测值
4. 检验两者之差是否在 $H_{\text{eff}} \to C_{\text{phys}}$ 时急剧扩大 → 推理-记忆相变

### 实验设计中需要特别注意的关键点汇总

#### 1. 训练数据的深度分布
- **核心原则**：训练深度分布是一个独立的实验变量，不是 nuisance parameter
- 需要系统地变化 $L_{\text{train}}^{\max}$，而不是固定一个"合理"的值
- 如果阶段 1 发现泛化效应显著，则阶段 2 的所有结论都需要标注"在 $L_{\text{train}}^{\max}=X$ 条件下"

#### 2. 随机种子的作用
- 每个 $(L, B)$ 条件需要多个种子（≥50）以得到稳定的准确率估计
- DAG 的随机生成（哪条是正确路径、干扰边如何连接）会显著影响单条难度
- 报告结果时应同时报告均值和方差

#### 3. 准确率阈值的选取
- 崩塌边界的定义依赖于阈值（如 70% 或 50%）
- 建议报告多个阈值下的 $\beta$，展示 $\beta$ 对阈值选择的鲁棒性
- 或者使用连续指标（如 AUC）而非二元阈值

#### 4. 模型尺寸的对照
- 至少测两个模型尺寸（如 7B 和 13B）以验证 $\beta$ 的物理含义
- 预测：更大模型 $\beta$ 更小 → 深度惩罚更弱 → 崩塌边界在更大的 $(L, B)$ 处
- 如果更大模型 $\beta$ 不变或更大，需要重新审视理论

#### 5. 位置编码的影响
- RoPE 等位置编码在长序列上的衰减可能贡献了部分 $\beta L$
- 可以对比不同位置编码方案（RoPE vs ALiBi vs NoPE）下的 $\beta$
- 这能让 $\beta$ 从"黑箱常数"变为"可分解的架构效应"

#### 6. 泛化 vs 记忆的混淆
- 在低深度训练 + 高深度测试场景中，模型的高准确率可能来自两种机制：
  - **真正的推理泛化**：学会了寻路策略，能推广到更长链
  - **局部模式匹配**：每步独立决策，不依赖长程一致性
- 如何区分？设计"陷阱测试"：在高深度测试中插入需要全局上下文才能正确决策的步（如"前面选了 A 所以这里必须选 B"），如果模型只在局部一致但全局矛盾，说明是模式匹配而非真推理
