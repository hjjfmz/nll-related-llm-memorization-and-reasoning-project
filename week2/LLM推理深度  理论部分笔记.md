## 1. 问题形式化与原有熵框架

### 1.1 任务定义

考虑一个有向无环图（DAG）上的最短路径查询任务。给定起点 $s$、终点 $t$ 及图的完整描述（以 token 序列形式输入），要求模型输出从 $s$ 到 $t$ 的一条合法路径（token 序列）。图的结构特征概括为逻辑 $G$。

- 输入问题：$X$（token 序列）
    
- 输出答案：$Y = (y_1, y_2, \dots, y_L)$，长度为 $L$ 的 token 序列
    
- 词典大小：$V$（所有可能 token 的数量）
    
- 图在节点 $i$ 处的出度（合法后继数）：$B_i$
    

### 1.2 全随机搜索熵 $H_R$

如果模型对图结构毫无掌握，只是随机猜词，则每一步均面对 $V$ 个等可能 token，答案序列的总熵为：

$$H_R = \sum_{i=1}^{L} \log_2 V$$

**物理意义**：这是“硬记”所有可能路径所需的最大信息存储量，也是我们量度逻辑压缩效果的参照零点。

### 1.3 逻辑约束熵 $H_G$（原定义）

若模型完美内化了图结构 $G$，那么在第 $i$ 步，它仅需从合法的 $B_i$ 个后继中做出选择。此时总不确定性降至：

$$H_G = \sum_{i=1}^{L} \log_2 B_i$$

**物理意义**：逻辑本身所固结的信息量。理论上，逻辑习得所能带来的最大压缩量为：

$$\Delta \text{NLL}_{\text{theory}} = H_R - H_G$$

这构成了原方案的核心度量。

### 1.4 $H_G$ 的盲区

原定义的致命缺陷随之显露：$H_G$ 仅仅是标量和，它无法分辨**深度**与**宽度**两种截然不同的难度来源。

- **深窄图**：$L=20$，$B_i\equiv 2$，则 $H_G = 20\times 1 = 20$ bit
    
- **浅宽图**：$L=2$，$B_1\approx 10^3$，$B_2\approx 2$，则 $H_G \approx 10+1 = 11$ bit（甚至可能设计成 20 bit）
    

> **深度解释：深窄 vs 浅宽的物理灾难差异**
> 
> 假设这两个图算出来的 $H_G$ 都是 20 bit。在以前的理论中，它们对大模型来说一样难。但事实上：
> 
> 1. **浅宽图** 就像面对一个包含上千个岔路口的大转盘，模型需要瞬间的“极高分辨率”来选出唯一正确的路。这考验的是局部特征提取能力。
>     
> 2. **深窄图** 则像走迷宫，每个路口只有左或右，但要连走 20 步。这考验的是长程上下文记忆，任何一步选错，后面的推理直接作废。
>     
>     原有的求和公式 $H_G$ 把它们粗暴地压扁成同一个数字，掩盖了产生推理崩溃的两种不同机制。
>     

两者 $H_G$ 可人为调至相等，但推理特性迥异：深窄图考验长程一致性与错误链条的乘性坍塌；浅宽图考验局部极端高维分类。$H_G$ 将这两者强行压入一维直线，因而无法预测准确率会在何种拓扑下崩塌。我们需要解耦这两个维度。

## 2. 推理的有噪信道建模

### 2.1 类比基础：逐 Token 推理即信号序列传输

将模型自回归生成正确答案的过程，想象为一个**经过一连串噪声信道的信号传播**：

- **信号**：正确路径上的每一步正确 token（每步可视为一个“码字”）
    
- **噪声**：图中该节点的其他合法后继（出度中除去正确后继的 $B_i-1$ 个分支），它们在嵌入空间中形成干扰向量。
    

每一步，模型实质上面对一个 $B_i$ 选 1 的分类问题。正确选项是信号，错误选项是加性噪声（在高维语义空间中的噪声矢量叠加）。

### 2.2 局部信噪比 (Step-wise SNR) 的严格定义

对第 $i$ 步，当已知图结构时，总的不确定性为 $\log_2 B_i$。这 $\log_2 B_i$ 比特中，可以解耦为两部分：

1. **正确路径本身的标记信息**：如果模型已经通过逻辑“知道”哪条是正确路径，那么这一步对它而言不存在信息量——但这是事后视角。从设计角度看，我们需要一个“信号功率”的基准。最自然的基准是**二元决策的最小单位**：即使 $B_i=2$，模型仍需做出一个“是或否”的二元选择来区分正确与错误。这 1 比特即为**信号本身的信息**（在通信中，这相当于每个传输符号携带 1 比特有效载荷）。
    
2. **纯干扰噪声**：剩下的 $\log_2 B_i - 1$ 比特，完全来自于多于一个的错误分支，它们形成干扰。
    

> **深度解释：为什么要单独抠出“1 比特”？**
> 
> 任何选择，哪怕是最简单的二选一（正确或错误），也需要消耗 1 比特的信息量来做决定。这就是我们必须保留的“有效载荷（信号）”。而当分支选项变成 4 个、8 个时，多出来的不确定性（$\log_2 4 - 1 = 1$ 比特，$\log_2 8 - 1 = 2$ 比特）纯粹就是用来迷惑模型的“噪声”了。这样拆分，使得信号和噪声在数学上完全正交。

由此定义第 $i$ 步的**噪声功率**（比特尺度）：

$$N_i = \log_2 B_i - 1 \quad (B_i \ge 2)$$

对于 $B_i = 1$（无选择），该步没有推理意义，可约定 $N_i=0$ 且不贡献信号（因为无须决策）；对于 $B_i=2$，$N_i=0$，对应**理想无噪声信道**。

**信号功率**统一归一化为 $S_i = 1$（单位信号）。

于是，立即得到第 $i$ 步的**局部信噪比**（线性值，非分贝）：

$$\text{snr}_i = \frac{S_i}{N_i} = \frac{1}{\log_2 B_i - 1}, \quad (B_i > 2)$$

当 $B_i=2$，$\text{snr}_i \to \infty$；当 $B_i$ 极大，$\text{snr}_i \to 0$。这一指标精确捕捉了“宽度噪声墙”。

## 3. 深度惩罚的物理根源与数学推导

### 3.1 噪声累积与有效全局信噪比

在多步自回归生成中，前一步的决策失误会导致整条路径错误，且上下文残余噪声可能向后传播。为刻画这一现象，设第 $i$ 步的**累积噪声**为：

$$N_i^{\text{acc}} = N_i + \alpha N_{i-1}^{\text{acc}}, \quad N_1^{\text{acc}} = N_1$$

其中 $0 \le \alpha \le 1$ 为噪声残留因子，$\alpha=1$ 代表噪声完全不衰减（最坏情况）。此时总噪声为简单求和：

$$N_{\text{total}} = \sum_{i=1}^{L} N_i = \sum_{i=1}^{L} (\log_2 B_i - 1)$$

信号总功率取为步数 $S_{\text{total}} = L$（每一步贡献单位信号），定义**全局信噪比**：

$$\text{SNR}_{\text{global}} = \frac{S_{\text{total}}}{N_{\text{total}}} = \frac{L}{\sum_{i=1}^{L} (\log_2 B_i - 1)}$$

深窄图（$N_i\approx0$）即使 $L$ 很大，$\text{SNR}_{\text{global}}$ 依然极高；浅宽图（某一 $N_i$ 巨大）则即使 $L$ 很小，全局信噪比也会骤降。这已初步打破了原 $H_G$ 的等价类。

### 3.2 中断概率与可靠性要求的量化

然而仅凭全局信噪比还不够，因为**长链的错误传播是乘性的**。设第 $i$ 步的正确分类概率为 $1-p_i$。$p_i$ 与局部信噪比紧密相关：信噪比越低，$p_i$ 越大。在宽泛假设下，可合理取 $p_i = \min(1, \frac{1}{\text{snr}_i}) = \min(1, \log_2 B_i - 1)$ 等单调映射，但更保守的，可用信息论中错误指数的形式：对于 $B_i$ 元均匀随机信道，错误概率的下界由 Fano 不等式控制，并可近似为：

$$p_i \approx 2^{-(\log_2 B_i - 1)} = \frac{2}{B_i}$$

此式的意义是：干扰分支越多，每多一个，错误概率按倒数缩减，但不会完全消失。为不失一般性，我们只依赖 $p_i$ 随 $N_i$ 单调递增这一性质。

整个序列正确概率：

$$P_{\text{success}} = \prod_{i=1}^{L} (1-p_i) \le \exp\left(-\sum_{i=1}^{L} p_i\right)$$

若要求最终准确率不低于 $1-\epsilon$，则必须：

$$\sum_{i=1}^{L} p_i \le -\ln(1-\epsilon) \approx \epsilon$$

当 $L$ 增长时，即使每步 $p_i$ 极微，总和也会越过阈值。这意味着：要达到给定可靠性，仅靠降低单步噪声是不够的，还必须控制步数 $L$，或者通过**额外冗余**来压低每步的 $p_i$。

### 3.3 从信道容量界到有效逻辑熵

在通信系统中，为了在串联信道中可靠传输，实际可达速率必须低于容量，且通常需要**速率回退**以满足有限长度下的可靠性约束。香农的有限长度信道编码理论（正常近似）指出，给定错误概率 $\epsilon$，最大可达速率约为：

$$R \approx C - \sqrt{\frac{V}{L}} Q^{-1}(\epsilon) + \dots$$

其中 $V$ 为信道分散。这一精确形式可能复杂，但其核心启示是：**可靠性惩罚随 $L$ 单调增加**。

在本文的推理任务中，我们要传输的“有效载荷”是 $L$ 比特的正确路径信号。每一步的信道容量，若受噪声限制，可表达为：

$$C_i = 1 - \kappa (\log_2 B_i - 1) \quad (\text{当 } \kappa(\log_2 B_i - 1) < 1)$$

这里 $\kappa$ 是常数，表征该模型架构将噪声功率转化为容量损失的效率。平均来看，每一步可承载略小于 1 比特的净荷。可靠传输 $L$ 比特信号的必要条件是：

$$L \le \sum_{i=1}^{L} C_i - \delta L$$

其中 $\delta L$ 是深度带来的额外速率损失（源自有限长度界和中断概率的约束）。代入 $C_i$ 表达式，得：

$$L \le L - \kappa \sum_{i=1}^{L} (\log_2 B_i - 1) - \delta L$$

$$\Rightarrow \kappa \sum_{i=1}^{L} (\log_2 B_i - 1) + \delta L \le 0$$

> **深度解释：化腐朽为神奇的惩罚项 $\beta L$**
> 
> 上面那个不等式 $\kappa \sum (\log_2 B_i - 1) + \delta L \le 0$ 在现实中几乎不可能成立，因为噪声不可能是负数。这意味着，如果模型容量固定，纯靠“走完全程”根本无法保证正确率。
> 
> 换个角度想，要想强行完成任务，模型必须支付“额外的认知成本”来抵抗深度增加带来的失忆/断裂风险。因此，我们不能再单纯地把局部的熵相加了，**必须在原来的结构熵 $\sum \log_2 B_i$ 的基础上，强行加上一笔因为“路径太长”而额外征收的税（即 $\beta L$）**。

这显然不可行（除非噪声全零），因此可靠推理注定要求额外的计算资源或更深的网络来提升容量。在实际模型中，容量并非固定；我们将“能否推理”的界限等价地表述为：**任务所需的等效总熵不超过模型物理压缩能力 $C_{\text{phys}}$**。自然地定义**有效逻辑熵**为：

$$H_{\text{eff}} = \sum_{i=1}^{L} \log_2 B_i + \beta L$$

此处的 $\beta$ 从上述推导中凝结了**深度惩罚系数**，它定量表征了为补偿深度导致的可靠性下降而必须计入的“冗余熵”。它的理论值可由 $\delta/\kappa$ 等导出，在实验中则通过测准崩塌边界反标定。

注意，该公式不是经验凑合，而是信道定理的限制条件 $\kappa\sum (\log B_i -1) + \delta L \le 0$ 的等价重写：定义 $\beta = \frac{\delta}{\kappa} + 1$，移项后任务可行性条件为 $H_{\text{eff}} \le \frac{\kappa}{\kappa}?$ 让我们重新严谨写出：

可靠条件：$\kappa \sum (\log_2 B_i - 1) + \delta L \le 0 \Rightarrow \sum \log_2 B_i \le (1 - \frac{\delta}{\kappa}) L + \sum 1 = L$。若 $\delta>0$，右端小于 $L$，这意味着允许的总结构熵甚至可能低于 $L$，这显然不是常态。我们发现其根源在于假设了容量形式为 $C_i = 1 - \kappa N_i$，这可能过于悲观。更合理的建模是：每一步的小容量损失 $N_i$ 并不完全侵占信号空间，模型可以通过更深层网络或更多参数来补偿，因此我们应该把容量写为 $C_i = \log_2 V_i^{\text{eff}}$ 等。最终，我们不从容量不等式强行导出功能形式，而是转向更直接的概率界：要求 $\sum p_i \le \epsilon$，而每步的错误概率如 Fano 界可由 $H(Y_i|X,\text{past}) \approx \log_2 B_i - 1$ 的下界约束，因此保证可靠性的条件必须对 $\sum (\log_2 B_i - 1)$ 和 $L$ 同时设限。于是 $H_{\text{eff}} = \sum \log_2 B_i + \beta L$ 就是这一联合约束的简化标量表达，$\beta$ 反映了长度敏感度。该形式获得了坚实的直观支持。

### 3.4 不等错误保护的加权形式

若考虑到推理后期出错代价更高（功亏一篑），通信中的不等错误保护（UEP）自然引入权重：

$$H_{\text{SNR-aware}} = \sum_{i=1}^{L} w_i \log_2 B_i$$

其中权重 $w_i$ 随 $i$ 递增，最简单的形式为 $w_i = 1 + \gamma (i-1)$ 或 $w_i = e^{\lambda i}$。这一形式等价于将深度惩罚按位置非均匀分配，比常数 $\beta$ 更精细地刻画了“越往后越脆弱”的物理特性。

## 4. 与全随机熵 $H_R$ 的无缝嵌入

现在，我们将新定义稳妥地放入原有两极框架。

原有关系：

$$\Delta \text{NLL}_{\text{theory}} = H_R - H_G = \sum_{i=1}^{L} (\log_2 V - \log_2 B_i)$$

这代表“死记硬背”相对“理想推理”所节省的比特总数。但在现实中，由于深度惩罚和噪声累积，模型无法逼近理想下界 $H_G$，其**实际可达的最低熵**是 $H_{\text{eff}}$（或加权形式）。因此定义**物理可实现的压缩量**：

$$\Delta \text{NLL}_{\text{eff}} = H_R - H_{\text{eff}} = \sum_{i=1}^{L} (\log_2 V - \log_2 B_i) - \beta L$$

（加权形式中，对应项变为 $\sum (\log_2 V - w_i \log_2 B_i)$）

这一公式保留了原框架的全部逻辑，只是用 $H_{\text{eff}}$ 替换了 $H_G$。当 $\beta=0$ 或权重退化为 1 时，还原为理想情况。其物理图像一目了然：

- **天花板发生的条件**：当 $H_{\text{eff}}$ 接近甚至超过模型的物理压缩上限 $C_{\text{phys}}$ 时，$\Delta \text{NLL}_{\text{eff}}$ 趋近于零或负值，模型已无法通过逻辑进一步压缩，只能退行至记忆或瞎猜，准确率急剧下降。
    
- **深窄图**：$\sum \log B_i$ 小，但 $L$ 大，$\beta L$ 项显著，天花板可能由深度惩罚主导。
    
- **浅宽图**：$\sum \log B_i$ 中某步极大，虽然 $L$ 小，但该项直接推高 $H_{\text{eff}}$，表现为宽噪声墙。
    

特别地，加权形式 $H_{\text{SNR-aware}}$ 与 $H_R$ 的差值，能敏锐捕捉到“早期宽步”的致命性：若第一步权重已升高或 $\log B_1$ 极巨，压缩量锐减。

由此，我们既保留了原始理论关于“逻辑即压缩”的优雅视角，又为现象学的“深度天花板”嵌入了坚实的信道理论根基。两者之间毫无矛盾，唯一下界被合理地上修。

## 5. 讨论：局限性与实验标定

### 5.1 假设的边界

我们的推导依赖于几个核心假设：

- 推理过程可建模为独立的离散无记忆信道串联，实际模型存在注意力等跨步耦合，但该假设抓住了最主要的一阶效应。
    
- 噪声形式 $\log_2 B_i - 1$ 及线性深度惩罚 $\beta L$ 在极深或极大宽度时可能需要修正，但对揭示拐点已足够。
    
- 常数 $\beta$ 与模型架构和尺寸有关，需实验标定，这不构成理论瑕疵，而是通往预测的通道。
    

### 5.2 如何在实验中测定 $\beta$

建议采用二维网格实验：构造不同 $(L, \bar{B})$ 组合（平均分支对数），测量准确率突降边界。拟合边界线 $L \cdot (\bar{B})^{\kappa} = \text{const}$ 或 $\sum \log B_i + \beta L = \text{const}$，即可反解 $\beta$ 及 $\kappa$，从而验证理论。

### 5.3 加权形式的先验权重

权重的具体函数形式可由模型在递增深度下的早期错误位置分布实验测定，亦可采用指数增长作为默认先验，或由信噪比的倒数动态确定。
