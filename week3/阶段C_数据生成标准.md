# 阶段 C：数据生成标准

> 版本：方案稿 v1  
> 范围：实验一至实验三的数据前置  
> 对齐工作：Morris et al. [1] 的随机序列容量测量、Xu et al. [2] 的受控图规划任务  
> 当前不涉及：混合比例实验、非均匀出度、递归/CoT 干预、非线性深度函数

---

## 1. 文档目标

本阶段先建立两套彼此独立、但在词表、答案长度和模型接口上可对齐的数据生成器：

1. **随机序列生成器**：复现 Morris et al. [1] 的纯记忆容量测量；
2. **分层 DAG 生成器**：在新图上测量单次前向、仅终答监督下的路径推理能力。

数据生成器必须先通过结构正确性、信息量计算、数据泄漏和捷径排查，才允许进入正式训练。实验一负责完成这一准入检查。

---

## 2. 统一符号与样本接口

| 符号 | 含义 |
|---|---|
| $V$ | 可用于节点名和随机答案的有效词表大小 |
| $S$ | 随机序列的答案长度 |
| $L$ | DAG 从起点到终点的路径步数 |
| $d$ | 主路径节点的固定出度 |
| $W$ | 每个中间层的节点数，要求 $W \ge d+1$ |
| $P$ | 模型非嵌入参数量或论文最终约定的统一参数口径 |
| $N$ | 训练样本数 |
| $X$ | 输入前缀 |
| $Y$ | 监督答案序列 |

所有数据均输出为统一记录：

```text
sample_id, family, split, seed, V, answer_length, input_ids, target_ids, metadata
```

其中 `family` 取 `random` 或 `dag`；`metadata` 保存图结构参数、理论信息量、正确路径和完整性检查结果。训练代码不得根据 `family` 使用不同的模型结构或优化器。

## 3. 随机序列生成器

### 3.1 生成目的

随机序列用于测量模型对不可泛化数据的训练集压缩能力。由于每个目标 token 独立、均匀地采自大小为 $V$ 的词表，单样本理论信息量为

$$
H_R = S\log_2 V.
$$

数据集总信息量为 $N H_R$。该设置只允许模型记忆训练样本，不能从样本之间学习可迁移规律。

### 3.2 样本格式

每个样本包含一个唯一、随机且与目标独立的样本键：

```text
[BOS] [KEY] k_1 ... k_q [SEP] y_1 ... y_S [EOS]
```

- `KEY` 仅用于定位训练样本，不得编码目标内容；
- $y_i$ 从有效词表中独立均匀采样；
- loss 只计算在 $y_1,\ldots,y_S$ 上；
- 键长度 $q$ 在同一实验组内固定；
- 训练集和验证集使用不同 seed，并检查键与目标均不重复。

唯一键是必要设计：没有输入键时，同一前缀对应大量互相冲突的随机答案，模型测到的是条件分布熵，而不是逐样本记忆容量。

### 3.3 容量测量口径

纯记忆量必须在**训练集**上计算：

$$
M_{\mathrm{train}}
=
N H_R-\mathrm{NLL}_{\mathrm{train,total}}.
$$

验证集只用于确认不可泛化性。合理结果应表现为：

- 训练集 NLL 随训练下降，$M_{\mathrm{train}}$ 上升并最终饱和；
- 未见过的随机序列上，单 token NLL 维持在约 $\log_2 V$；
- 容量结论不得由验证集随机序列的 NLL 推导。

### 3.4 与 DAG 数据的对齐

在需要比较随机与 DAG 管线时，随机序列应至少提供两种版本：

1. **原始容量版**：严格服务于 Morris 容量复现；
2. **长度匹配版**：令 $S=L$，并使前缀 token 数与对应 DAG 组近似一致，用于排除上下文长度和输出长度造成的测量差异。

实验二以原始容量版为主，长度匹配版仅作为管线控制。

## 4. 分层 DAG 生成器

### 4.1 任务定义

输入给出一张随机命名的分层有向无环图、起点 $s$ 和终点 $t$；模型输出从 $s$ 到 $t$ 的唯一可达路径：

```text
[BOS] [GRAPH] u_1 v_1 ... u_E v_E
[QUERY] s t
[ANSWER] p_1 ... p_L [EOS]
```

- 边对顺序逐样本随机打乱；
- 节点名逐图重新采样，不携带层号、路径身份或语义；
- loss 只计算答案路径；
- 模型只能进行一次自回归前向生成，不提供中间搜索轨迹或 CoT 监督。

### 4.2 严格分层结构

图包含第 $0$ 至第 $L$ 层，所有边只允许从第 $i$ 层指向第 $i+1$ 层，因此拓扑上必然无环。

1. 在每层采样 $W$ 个随机命名节点；
2. 指定 $p_0=s,p_1,\ldots,p_L=t$ 为唯一目标路径；
3. 对每个主路径节点 $p_i$，连接正确后继 $p_{i+1}$，并连接 $d-1$ 个下一层干扰节点；
4. 对每个非主路径节点，也生成 $d$ 条指向下一层非主路径节点的边；
5. 禁止任何非主路径节点连接到后续主路径节点，特别是禁止连接到 $t$；
6. 所有非终层节点保持相同出度 $d$，消除“低出度即正确路径”的局部捷径。

该结构保证：

- 从 $s$ 到 $t$ 只有一条有向路径；
- 每一步正确后继都位于 $d$ 个局部候选之中；
- 干扰分支在局部具有与正确分支相同的出度外观；
- 找到答案需要跨层追踪到目标，而不能通过节点命名或局部度数直接判断。

### 4.3 结构难度锚点

对于固定出度、唯一目标路径的组，定义

$$
H_L = \sum_{i=1}^{L}\log_2 d = L\log_2 d.
$$

在阶段 C 中，$H_L$ 被用作**结构搜索难度锚点**，用于组织不同 $(L,d)$ 条件和计算经验指标。由于完整图已包含在输入中、正确路径在给定图后是确定的，$H_L$ 不应表述为严格的条件熵下界；模型可能对正确路径给出高于 $2^{-H_L}$ 的概率。因此：

- 不把 $\mathrm{NLL}\ge H_L$ 设为数据或模型必须满足的硬约束；
- $\rho=(H_R-\mathrm{NLL})/(H_R-H_L)$ 作为经验归一化坐标时不强制截断到 $[0,1]$；
- $\lambda=(\mathrm{NLL}-H_L)/L$ 允许为负值，最终解释依赖实验结果。

这一口径校正不改变当前实验要检验的线性关系，只避免把经验锚点误写成香农意义上的必然下界。

### 4.4 序列长度与图规模

完整边数为

$$
E=L W d,
$$

输入边列表长度约为 $2E$ 个节点 token。正式比较不同 $L$ 或 $d$ 时，应记录并报告：

- 输入 token 数；
- 图节点数与边数；
- 输出 token 数；
- 有效上下文占用比例。

阶段 C 前三项实验以“测量管线建立”为主，不宣称已经完全分离深度、图规模和上下文长度效应。深度效应的正式因果分离应由后续控制实验完成。

## 5. 数据划分与防泄漏

### 5.1 随机序列

- 训练、验证和测试集合使用互斥 seed；
- 检查样本键、目标串及其组合无重复；
- 训练集用于容量测量，验证集用于不可泛化性检查。

### 5.2 DAG 序列

采用三级泛化划分：

1. **IID 新图测试**：$(L,d,W)$ 与训练相同，但节点命名和边集全部重采样；
2. **同结构新命名测试**：固定拓扑、重新置换节点 token，检测名称记忆；
3. **边序重排测试**：固定图和查询，仅重排边列表，检测位置捷径。

主结果使用 IID 新图测试。同结构新命名和边序重排仅作为数据有效性诊断，不与主结果混合汇报。

## 6. 生成器准入测试

每个数据配置至少通过以下自动检查：

| 检查项 | 通过标准 |
|---|---|
| DAG 性质 | 拓扑排序成功，且所有边从第 $i$ 层指向第 $i+1$ 层 |
| 唯一路径 | 从 $s$ 到 $t$ 的有向路径数严格等于 1 |
| 路径长度 | 唯一路径边数严格等于 $L$ |
| 出度控制 | 所有非终层节点出度等于 $d$ |
| 干扰有效性 | 非主路径节点均不可达 $t$，且局部出度不暴露身份 |
| 理论量 | 记录值满足 $H_R=S\log_2V$、$H_L=L\log_2d$ |
| 序列化可逆 | 从 token 序列可无歧义恢复图、查询和答案 |
| 边序不变性 | 多次打乱边序不改变标准答案 |
| 数据互斥 | 训练、验证和测试无重复样本或重复图哈希 |
| 词频平衡 | 节点 token 在路径/干扰位置的边际频率无系统偏差 |

任一结构性检查失败时，整批数据作废并重新生成。

## 7. 数据统计报告

每次生成后固定输出一份统计摘要：

```text
配置参数：V, S 或 (L, d, W), seed
样本规模：train / validation / test
长度统计：input / target / total tokens
图统计：nodes / edges / path count
信息量：H_R / H_L
重复率：keys / targets / graph hashes
准入测试：各项 pass/fail
```

论文正文报告关键参数和划分原则，完整生成配置、seed 与统计摘要放入附录或复现实验材料。

---

## 8. 本阶段交付边界

数据生成部分完成的判据不是“生成出若干样本”，而是：

1. 两类生成器均能稳定产生可解析数据；
2. 所有准入测试通过；
3. 随机序列确实不可泛化；
4. DAG 数据不存在名称、边序或度数捷径；
5. 理论量和实测数据字段可直接供实验一至三调用。
