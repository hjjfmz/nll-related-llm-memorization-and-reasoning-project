# 阶段 C：前三个主实验方案

> 版本：论文方案稿 v1  
> 依赖文档：`阶段C_数据生成标准.md`  
> 研究范围：RQ1 的测量管线、记忆容量半边与推理半边  
> 当前假设：仅检验 $\mathrm{NLL}\approx H_L+\lambda L$ 的线性基准，不引入其他函数族

---

## 1. 方案总览

前三个实验形成递进关系：

1. **实验一验证测量管线是否可信**；
2. **实验二用随机序列标定模型的实测记忆容量 $\alpha P$**；
3. **实验三用纯 DAG 新图测试测量路径推理表现与经验深度惩罚 $\lambda$**。

实验二和实验三不得并行解释为同一种能力：实验二测训练样本的记忆压缩，实验三测未见图上的结构泛化。只有在两套管线分别成立后，后续阶段才讨论二者是否能进入同一容量账本。

---

## 2. 共同实验协议

### 2.1 模型族

采用同一类 decoder-only Transformer，并构造多个参数规模。所有规模保持以下设计原则一致：

- tokenizer 和有效词表一致；
- 位置编码类型一致；
- 优化器、学习率调度和训练停止规则一致；
- 参数量 $P$ 使用统一统计口径；
- 上下文窗口覆盖所有实验输入，不发生截断；
- 不使用预训练权重，避免外部知识和词义影响。

论文方案阶段暂不锁死层数、隐藏维度和参数量网格。正式执行前，根据单卡预算选择至少三个能够覆盖欠容量、过渡区和过参数化区的规模。

### 2.2 训练与评估

- 每个主要配置使用多个独立 seed；
- checkpoint 按预先规定的训练步数或 token 数保存；
- 训练停止由验证曲线平台决定，不以测试集结果选 checkpoint；
- 所有 NLL 换算为 bit，并同时报告总 NLL 与每 token NLL；
- DAG 主评估使用未见过的新图；
- Exact Match、逐步准确率和首错位置用于解释 NLL，不替代 NLL 主指标。

### 2.3 共同指标

| 指标 | 使用位置 | 解释 |
|---|---|---|
| 训练集总 NLL（bit） | 实验一、二 | 计算随机数据的已记忆信息量 |
| 测试集 NLL（bit） | 实验一、三 | 测量新图上的路径概率质量 |
| $M_{\mathrm{train}}$ | 实验二 | $N H_R-\mathrm{NLL}_{\mathrm{train,total}}$ |
| Exact Match | 实验一、三 | 与 Depth Ceiling 的离散崩塌口径对齐 |
| 条件逐步准确率 | 实验三 | 在此前 token 正确时，第 $i$ 步是否正确 |
| 首错位置 | 实验三 | 判断错误是否随深度向前移动 |
| 路径合法率 | 实验三 | 输出是否由图中真实边组成 |
| $\lambda$ | 实验三 | $(\mathrm{NLL}-H_L)/L$ 的经验观测量 |

## 3. 实验一：数据与测量管线自洽性验证

### 3.1 实验目的

实验一不用于证明核心理论，而用于回答更基础的问题：生成的数据是否真的对应预期任务，NLL 和派生指标是否按定义计算，模型是否依赖数据捷径。只有实验一通过，实验二和实验三的数值才具备解释资格。

### 3.2 子实验 1A：随机序列管线校准

**设计。** 选取一个小模型和一个中等模型，在小规模随机序列数据上训练至明显记忆。分别测量训练集和未见随机序列上的 NLL。

**预期模式。**

- 训练集 NLL 显著下降；
- 未见随机序列每 token NLL 接近 $\log_2V$；
- 打乱样本键与目标的对应关系后，训练集 NLL 恢复到随机水平；
- $M_{\mathrm{train}}$ 的实现值与直接累加的 token 级压缩量一致。

**通过标准。** 管线必须同时显示“训练集可记忆、测试集不可泛化”。若测试集也显著优于随机水平，应优先排查随机数、重复样本、键泄漏和非均匀词频。

### 3.3 子实验 1B：DAG 结构与算法可解性校准

**设计。** 对若干小 $(L,d,W)$ 配置生成数据，先用确定性图搜索程序求解，再与生成器保存的标准路径比较。

**通过标准。**

- 自动求解器 Exact Match 为 100%；
- 每张图仅有一条 $s\rightarrow t$ 路径；
- 路径长度、出度和层数与配置完全一致；
- 随机重命名节点、打乱边序后答案的结构身份不变。

该子实验验证任务本身可解，但不把 $H_L$ 误作严格 NLL 下界。$H_L$ 只作为结构难度坐标参与后续分析。

### 3.4 子实验 1C：捷径压力测试

对同一批测试图构造三种变体：

1. 原始序列；
2. 节点名随机置换；
3. 边列表重新打乱。

模型在三种版本上的表现应在 seed 波动范围内一致。若差异明显，说明模型利用了节点频率、命名或边位置捷径，数据生成器必须先修正。

另设两个负对照：

- **删图对照**：移除边列表，仅保留 $(s,t)$；性能应接近随机；
- **错图对照**：保持答案不变但替换输入图；性能应显著下降。

这两个对照用于确认模型输出依赖输入图，而不是仅记住答案先验。

### 3.5 实验一输出

实验一形成一张“管线准入表”，逐项报告：

- 随机序列训练/测试 NLL；
- 图求解器正确率；
- 唯一路径和出度检查；
- 重命名/边序扰动前后的性能差；
- 删图/错图负对照结果。

所有结构检查必须通过；行为检查若失败，不进入实验二和实验三。

## 4. 实验二：纯随机序列记忆容量标定

### 4.1 研究问题

实验二回答：在本项目所用模型、精度和训练协议下，模型最多能在训练集中压缩多少随机信息，该容量是否近似满足

$$
M_{\max}(P)=\alpha P+c?
$$

该实验复现 Morris et al. [1] 的测量逻辑，并为后续实验提供项目内实测的 $\alpha$，而不是直接把文献中的约 $3.6$ bits/parameter 当作固定常数。

### 4.2 实验变量

**自变量：**

- 模型参数量 $P$；
- 随机数据集总信息量 $N S\log_2V$。

**控制变量：**

- 词表 $V$、答案长度 $S$ 和样本键格式；
- 模型族、数值精度、训练 token 预算和优化协议；
- 每个参数规模覆盖从数据量不足到容量饱和的多个数据规模。

**因变量：**

- 训练集总 NLL；
- $M_{\mathrm{train}}$；
- 每参数记忆量 $M_{\mathrm{train}}/P$；
- 未见随机序列 NLL；
- 训练与验证损失随训练进程的变化。

### 4.3 实验流程

1. 对每个 $P$ 生成多个随机数据规模，使总数据比特量跨越预期容量区间；
2. 每个配置训练至训练 NLL 不再稳定下降；
3. 计算每个数据规模下的 $M_{\mathrm{train}}$；
4. 取各参数规模的饱和值 $M_{\max}(P)$；
5. 拟合 $M_{\max}(P)$ 与 $P$ 的线性关系，报告斜率 $\alpha$、截距和置信区间；
6. 用未见随机序列确认模型没有从数据分布中获得可泛化压缩。

### 4.4 与 Morris baseline 的公平对齐

核心对齐项包括：

- 均匀随机 token；
- 已知且可解析的数据总熵；
- 在训练数据上测量记忆压缩；
- 多参数规模和多数据规模扫描；
- 以 bits/parameter 报告容量。

若模型架构、精度或参数统计口径与 Morris 不完全一致，论文中不把数值偏差直接解释为复现失败，而先报告协议差异。项目内实测 $\alpha$ 是后续分析的唯一容量标定值。

### 4.5 主要图表

1. **容量曲线**：横轴为数据集总信息量，纵轴为 $M_{\mathrm{train}}$，每条线对应一个 $P$；
2. **缩放图**：横轴为 $P$，纵轴为 $M_{\max}$，显示线性拟合与置信区间；
3. **泛化负对照**：训练集与未见随机序列的每 token NLL 对比；
4. **训练动力学图**：选取代表配置展示训练/验证 NLL 随训练步数的变化。

### 4.6 支持与证伪标准

**支持容量标定：**

- $M_{\max}$ 随 $P$ 单调增长；
- 线性模型能稳定描述所测参数范围；
- $M_{\max}/P$ 在主要规模上接近稳定；
- 未见随机序列仍接近随机预测。

**不能支持容量标定：**

- 容量饱和值未出现；
- 结果主要由训练未收敛决定；
- 测得的“压缩”同样出现在未见随机序列；
- 不同 seed 的容量估计差异与规模效应同量级。

实验失败时，只能说明当前训练协议尚未得到可靠 $\alpha$，不得继续用文献常数替代并宣称本项目容量已被标定。

## 5. 实验三：纯 DAG 推理极限与深度惩罚测量

### 5.1 研究问题

实验三回答三个递进问题：

1. 模型能否在未见过的新图上学习可迁移的路径搜索；
2. 随 $L$ 增加，NLL、Exact Match 和首错位置如何变化；
3. 在固定模型和数据协议下，经验量

$$
\lambda(L,d,P)=\frac{\mathrm{NLL}-H_L}{L}
$$

是否在当前测量区间内近似稳定，并能否与实验二标定的 $\alpha P$ 共同描述性能崩塌位置。

实验三只检验当前线性基准，不比较幂律、指数或对数候选。

### 5.2 数据与训练设置

- 仅使用纯 DAG 数据，不混入随机序列；
- 每个 $(L,d,W)$ 训练组独立生成训练、验证和测试图；
- 主结果均在 IID 新图测试集上计算；
- 每组训练深度与测试深度相同，先测“对角线”表现；
- 不在本实验中使用“浅层训练、深层测试”结果估计 $\lambda$；
- 选择足够训练数据，使新图验证性能已经稳定，避免把未学会算法误判为深度惩罚。

这里的“足够训练数据”由学习曲线确认，不预先依赖尚未由后续实验测得的 $N^*$。

### 5.3 实验变量

**自变量：**

- 路径深度 $L$；
- 固定出度 $d$；
- 模型参数量 $P$。

**控制变量：**

- 每层宽度 $W$ 的生成规则；
- 节点词表、序列化模板和边序随机化；
- 训练协议与收敛标准；
- 每个配置的新图测试规模。

**需要同步记录的混杂量：**

- 图节点数和边数；
- 输入 token 数；
- 输出 token 数；
- 上下文占用比例。

由于输入规模随 $L$ 和 $d$ 变化，实验三首先建立联合现象图，不单独声称深度已经与图规模完全因果分离。该分离由后续实验完成。

### 5.4 基线与对照

1. **随机选择基线**：每步从 $d$ 个候选中均匀选择，用于给出 Exact Match 和逐步准确率的机会水平；
2. **确定性图搜索上界**：标准算法在所有数据上应达到 100% Exact Match；
3. **删图/错图对照**：验证模型依赖图输入；
4. **Depth Ceiling 口径对齐**：报告按深度变化的离散成功率和崩塌位置，但不声称任务结构与 star graph 完全等价；
5. **NLL 连续测量**：作为相对离散准确率的主要新增信息，显示崩塌前后的概率质量变化。

Fano 准确率上界在本批实验中作为理论参照，不作为需要重新实现的方法 baseline；待任务变量和容量口径完全对齐后再决定是否进行数值复现。

### 5.5 测量流程

1. 先在容易配置上确认模型能够对新图泛化；
2. 固定 $d$ 和 $P$，逐步增加 $L$；
3. 对每个配置训练至验证集指标平台；
4. 在新图测试集上测量 NLL、Exact Match、条件逐步准确率、路径合法率和首错位置；
5. 计算对应的 $H_L=L\log_2d$ 与经验 $\lambda$；
6. 对不同 $P$ 重复深度扫描，比较崩塌位置是否随实测容量移动；
7. 将观察到的崩塌位置与基于实验二 $\alpha P$ 和当前 $\lambda$ 的预测作对照。

崩塌点应由预先固定的性能准则定义，例如 Exact Match 显著脱离高性能平台，或 NLL 相对浅层趋势出现明确拐点。正式执行前只选择一种主定义，其余定义作为稳健性检查，避免事后挑选阈值。

### 5.6 主要图表

1. **深度性能曲线**：横轴 $L$，纵轴分别为测试 NLL 和 Exact Match；
2. **逐步错误图**：横轴为路径位置，纵轴为条件逐步准确率；
3. **首错位置分布**：比较崩塌前、临界区和崩塌后的错误位置；
4. **经验 $\lambda$ 图**：横轴 $L$，纵轴 $(\mathrm{NLL}-H_L)/L$，按 $P$ 分组；
5. **预测-观测崩塌图**：比较容量公式给出的预测深度与实测深度；
6. **输入依赖控制表**：原图、重命名、边序重排、删图和错图条件的结果。

### 5.7 支持与证伪标准

**支持“学到可迁移图推理”：**

- 新图性能显著高于随机选择基线；
- 重命名和边序重排不显著改变性能；
- 删图或错图使性能明显下降；
- 输出路径具有较高图内合法率。

**支持当前线性深度惩罚基准：**

- 在预先指定的有效区间内，$\lambda$ 的跨深度变化小于 seed 和测量误差可解释范围；
- 使用浅/中深度估计的 $\lambda$ 能预测更深配置的 NLL 或崩塌位置；
- 不同参数规模的崩塌移动方向与实验二标定的容量变化一致。

**证伪或暂不支持：**

- $\lambda$ 随 $L$ 系统漂移，且漂移大于不确定性；
- 模型只在训练图上成功，在新图上接近随机；
- 崩塌主要由输入超长、图规模或训练未收敛解释；
- 容量预测与实测崩塌位置无稳定关系。

若线性基准不成立，本阶段只报告其失败，不在当前文档中追加其他函数形式。

## 7. 论文写作边界

在实验结果产生前，正文只能使用“检验”“测量”“评估”等措辞，不得提前写成：

- 已证明 $\lambda$ 为常数；
- 已证明 $H_L+\lambda L=\alpha P$ 是普适定律；
- 已证明模型在记忆与推理之间共享同一物理容量；
- 已复现约 $3.6$ bits/parameter；
- 已证明性能下降仅由深度造成。

前三个实验完成后，先依据 Claim-Evidence Map 更新可支持的结论，再进入记忆/推理混合与深宽分离实验。
